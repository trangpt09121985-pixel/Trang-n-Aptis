VD1: Before the trip I was very excited because I had never been there. When I arrived, wow, Dalat was so stunning with hills, trees, and many kinds of flowers. When I came home, I felt so relaxed and really wanted to return to Dalat one day. Although this happened a long time ago, everything is still in my mind and I will never forget.

VD2: At first, I felt really nervous because I had never spoken in front of many people. But after a few minutes, I felt better. I tried to speak confidently. When I finished my talk, everyone stood up and applauded. I felt so happy and proud of myself because I had tried my best. Although this happened a long time ago, everything is still in my mind and I will never forget.

VD3: Before the exam, I felt so tired and stressed because the exam was so difficult (challenging). But when I got the result, I felt relieved. It’s amazing. I was so happy and proud of myself because I had tried my best. Although this happened a long time ago, everything is still in my mind and I will never forget.

VD4: When I got the gift (present), I felt so excited that I jumped up and down like a child. It was one of the best presents I had got. I was grateful. The gift was so meaningful

VD5: I felt so relaxed and comfortable after busy days. It was one of the most memorable experiences in my life.
